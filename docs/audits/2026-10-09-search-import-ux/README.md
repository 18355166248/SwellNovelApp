# 搜书与网站导入交互走查

2026-10-09，使用当前源码和江测试机的 iPhone 镜像，走查搜书入口、站点选择、最近访问与网页书籍预览。本轮包含上一轮尚未提交的“网站导入”命名和每次回入口改动；沿用现有颜色、字体和注册书源，不改变解析和入库事务。

## 按步骤检查

| 步骤 | 页面与操作           | 当前发现                                                                                                | 调整                                                                                                                         |
| ---- | -------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 1    | 搜书、输入、搜索反馈 | 大面积深色网站入口比搜索按钮突出；输入后入口仍占据结果上方；空态重复解释搜索，正文反馈较弱              | 搜索按钮使用主色；网站入口改为轻量卡片，输入后让位给结果；收起提交后的键盘；无历史时提供简洁说明，历史与结果各用一个标题     |
| 2    | 网站入口与常用站点   | 大说明卡占据首屏；站点单列与搜索引擎混排；网址提示一行截断                                              | 收紧说明，给出“目录 → 识别 → 加入书架”；站点按注册表动态生成两列；搜索引擎单独一行；域名允许两行显示                         |
| 3    | 最近访问、返回入口   | 所有记录占据长列表，长网址省略后难区分；工具栏按钮仅图标且点击区域 34pt                                 | 默认展示最近 3 条，可展开全部；站名与网址分两行；返回入口后重新收起；工具栏点击区 44pt，提供朗读名称，入口增加明确“打开”按钮 |
| 4    | 书籍识别预览         | 《仙工开物》详情页仅识别当前页 16 个链接，却显示“共 16 章”，易误解为全书总量；长书名与作者/数量单行截断 | 数量改为“已识别 X 项目录”；标题与说明自然换行；识别、返回和关闭具有可访问名称；导入中不允许隐藏预览，继续显示进度            |

完整目录仍在实际入库前补全/合并。常用站点直接使用注册书源，后续增加站点无需再维护一套页面入口。

- `npm run check` 已通过：77 套件、556 项测试，TypeScript、ESLint 0 errors（188 条既有警告），Web production 构建通过（2 条包体积警告）。包含导入中关闭按钮保护，最终专项 18 项通过，受影响文件 ESLint 0 errors；原有目录识别、取消和入库回归保持。
- 本轮真机镜像文字输入受到宿主输入法影响，未将乱码查询当成正常书名搜索的视觉证据。正常搜索的分批返回、失败重试、空结果、取消和重复入库由组件/业务回归覆盖；不把它们等同于每个网站已完成在线验收。
- 已确认的可访问性改动为按钮名称、角色、禁用/忙碌/展开状态、点击区域与自然换行。未声称完成 VoiceOver、大字号、横屏或全量 WCAG 验收。
