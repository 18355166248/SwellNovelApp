## 修复

- 搜索引擎命中后原来不再查询书源列表，单站不可用时缺少备用入口。现在书源列表与引擎并行，合并、去重并分批展示；失败保留其他来源的有效候选，取消后的结果不再更新界面。
- 明智屋原来允许某分段 HTTP 成功但没有章节的响应参与合并，导致残目录入库。现在每段必须解析到本书章节，空段或请求失败会尝试另一镜像；两节点都无效时明确失败，不发布残目录。短书直接列出章节时使用当前目录页，减少多余请求。
- 明智屋目录只接受对应书号的分段与正文链接；TXT 图书下载网也先检查原始链接主机和书号，避免推荐区其他书籍章节被计入本书目录完整度。
- 通用 HTML 识别器改用标准 URL 解析 `../`、query 相对地址和 `&amp;` 参数；拒绝非 HTTP 链接。分页模板排除站外广告链接。

## 边界与后续重点

这是一条真实在线样本验收，不能推导所有书籍、所有网络或生产真机都成功。镜像重试和空段校验由受控响应测试验证；分段非空也不等于能识别所有形式的半截响应。当前在线导入仍有 45 秒解析上限，慢速长目录需要后续引入进度反馈与可取消的分阶段等待。搜索列表只查公开有限书目，未覆盖全站；部分页面须完成 WebView 挑战。不能通过放宽目录质量门槛来提高表面成功率。
