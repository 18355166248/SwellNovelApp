# 玄幻阁真机目录解析排查

设备：Swell5，iPhone 13 Pro Max，iOS 18.6.2。通过 iPhone 镜像操作 App；画面显示使用 4G。

## 复现与根因

- 《仙工开物》目录 `http://wap.xuanhuange.info/wapbook-192466/` 能打开，浏览器 DOM 识别出 40 条章节、30 页目录。
- 点击加入书架后，分页连续重试 3 次仍报“未识别到新章节，目录分页可能失效”。
- 在可见页面点击网站自己的“下一页”，能正常打开 `/wapbook-192466_2/`，显示第 30 ～ 69 章。
- 用开发调试器读取已确认的当前第二页 DOM，仅保存该目录 HTML；未提取未知网络缓存或小说正文。
- 同一份真机 HTML 使用 Node 标准 URL 时提取 40 条章节，换成项目实际安装的 React Native URL 后为 0 条。

实际链接 `/wapbook-192466-63854586/` 被 RN URL 错误解析为：

```text
http://wap.xuanhuange.info/wapbook-192466_2/wapbook-192466-63854586/
```

它无法匹配同书章节路由。可见页 DOM 使用 WebView 的浏览器 URL；分页 HTML 使用 RN JS 环境 URL，因此之前基于 Node/JSDOM 的回归没有暴露真机差异。RN URL 的 hash 处理也不满足当前页面身份校验的要求。

## 修复范围

- 原生目录识别器、浏览器导航校验显式使用 `react-native-url-polyfill@4.0.0`，不覆盖全局 URL。
- Web 和 Node 使用平台默认标准 URL，避免诊断脚本加载原生依赖。
- 新增使用实际 RN URL 环境的 3 项回归，覆盖分页相对链接、完整目录合并和页面身份校验；使用当前第二页的少量真实目录锚点，不包含正文。
- 保留玄幻阁适配和 loading 修复。
