# 网站导入流程补充审计

本轮从 `2b67d10` 继续检查正文请求、全本缓存、自动追更与目录替换之间的竞争，以及 React Native 与 Node 的 URL 行为差异。修改保持未提交。

## 复现与修复

| 问题                   | 原行为                                                                      | 修复                                                                |
| ---------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 正文和子页请求迟到     | 整个旧章节对象写回，回退追更修正的标题、顺序和地址                          | 共用正文发布函数，仅合并正文字段，保留最新目录身份与元数据          |
| 阅读与全本下载并发     | 首个子页可能覆盖完整正文；完整下载也可能被新的首屏缓存挡住                  | 完整缓存优先；相同正文前缀允许从部分缓存扩展到完整章                |
| 全本缓存目录重排、追加 | 固定数组下标导致漏章、重复章或按旧总数误报全部完成                          | 按稳定章 id 遍历，纳入中途新增章，重新计算实际完成数                |
| 自动追更缓存目录再变   | 虽然按来源挑出新章，抓取时仍使用旧数组下标                                  | 每次正文和子页请求前按新章 id 重新定位                              |
| 删除期间的迟到缓存     | 已移除书仍收到正文；防抖保存可在永久删除后重建孤立文件                      | 发布前检查书籍有效性，保存任务读取当前书库；任务计时器按 store 隔离 |
| 阅读触发旧残目录修复   | 先替换目录和阅读引用，落盘错误只记录日志                                    | 复用检查更新的共享事务，保存失败保留旧目录并向阅读器抛错            |
| 旧 host 来源缓存版本   | 下载器按注册源校验，阅读器按 host 校验，可能误报可离线                      | 使用书籍实际来源身份，过期浏览器版本重抓                            |
| 缓存按钮同帧连点       | state 尚未刷新，第二次点击启动第二个全本任务                                | 控制器 ref 同步锁定，第二次立即停止；旧 finally 不清理新任务        |
| RN URL 章节参数        | `token=a=b` 截断为 `token=a`，不同链接身份误合并                            | 身份解析共用标准 URL 与 URLSearchParams                             |
| RN URL 分页环路        | 原生 URL 属性不可写，规范化失败回退原始 URL，协议/域名/参数顺序变化绕过检测 | 分页身份使用标准 URL，不同子页参数仍保留                            |
| RN URL 明智屋章节      | 原生 URL 给 `.html` 地址追加斜杠，章节号正则返回 null                       | 明智屋等注册源统一使用已有平台标准 URL 模块                         |

正文质量校验在全本任务内按不可变章节对象复用，避免每下载一章都重新扫描已缓存整本正文。仍保持串行下载和定期保存。

## 真机与边界

江测试机（iPhone 12 Pro Max，iOS 18.7.8）已覆盖安装最终 Release 包并自动启动，保留原书架与进度。通过 iPhone 镜像实际验证：两本书与封面保留；《仙工开物》1165 项目录、约 1.2 万已缓存字数和 4/1165 项完整缓存保持；点击缓存显示“缓存中 0% · 停止”，再次点击立即显示“已停止，缓存了 4/1165 项正文”，按钮恢复。继续阅读仍返回第 2 章原来的 2/15 页及相同正文。

并发目录变更、磁盘保存失败以及原生 URL 输入矩阵使用确定性测试覆盖；不会把这些测试当成所有线上网站已经逐一验收。未强制模拟真机断电、文件写入中断或硬件存储损坏。站点改版、验证页和网络中断仍需通过诊断记录与可重试错误继续定位。
