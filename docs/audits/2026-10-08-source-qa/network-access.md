# 明智屋与玄幻阁连通性复查

日期：2026-10-08。用户报告物理 iPhone 的 4G 可访问，以下为 Mac 当前网络与模拟器的对照；尚未接入用户的 4G 热点。

## 结论

- 明智屋：Mac 默认 DNS 与两家加密 DNS 返回不同地址。默认路径连接超时；只为诊断请求换用加密 DNS 后，HTTPS 首页、详情、目录、正文均可读取，证书校验通过。不能把此前失败直接解释成网站停用或用户 4G 有问题。
- 玄幻阁：默认 DNS 与两家加密 DNS 返回一致，Mac 到对应地址的 HTTP/HTTPS 均连接超时。旧域名虽可响应，但跳回相同不可达站点；指定旧站地址则出现循环重定向，没有找到当前 Mac 网络下可用的替代链路。需要对照用户真机的完整网址及 4G 网络继续验证。
- App 明智屋原来强制先走服务器代理，代理 502 会阻断设备本来可用的路径。已改为设备直连优先，失败后保留代理、WebView 回退，并修复连通后暴露的实际页面解析问题。

## 浏览器与网络证据

Chrome 实际打开 `https://tw.mingzw.net/` 和 `http://wap.xuanhuange.info/`，均显示 `ERR_CONNECTION_TIMED_OUT`。Mac 没有启用系统 HTTP/HTTPS/SOCKS/PAC 代理，代理环境变量未设置。

| 主机                                      | Mac 系统 DNS    | Cloudflare / Google DoH |
| ----------------------------------------- | --------------- | ----------------------- |
| tw.mingzw.net                             | 168.143.171.189 | 204.12.242.220          |
| www.mingzw.net                            | 67.15.129.210   | 204.12.242.220          |
| wap.xuanhuange.info / www.xuanhuange.info | 172.247.2.131   | 172.247.2.131           |

两站的 tw/www 或 wap/www、HTTP/HTTPS 共八个默认路径请求，移动端 UA 下均在 TCP 连接阶段超时，没有进入 TLS 或收到 HTTP 响应。原始记录：[默认网络](./network-access.json)、[两家 DNS 对照](./network-dns.json)。

明智屋使用原域名、Host/SNI 与正常证书校验，指定 DNS 返回地址后，tw/www 首页及目标书详情均 HTTP 200，约 1.1–1.4 秒，`ssl_verify_result=0`。HTTP 测试只覆盖 80 端口时，收到升级 HTTPS 的 301 后再次超时，不能将 301 算作访问成功。记录：[指定解析地址](./network-resolved.json)。

随后使用 curl 的 `--doh-url=https://cloudflare-dns.com/dns-query`，无需固定 IP，即可完成下列真实解析。仅诊断请求使用该 DNS；没有改变 Mac、Chrome、iOS 的系统 DNS，也没有给 App 写入固定 IP 或关闭证书校验。

玄幻阁旧域名 `xuanyge.com` HTTP 跳至 `www.xuanhuange.info`；旧地址保留本站 Host 的请求则循环 301。记录：[旧站路径复查](./network-xuan-origin.json)。先前公网代理返回 `Host not allowed`，与仓库内已有白名单不一致；仍需核对部署版本，本轮没有部署。

## 明智屋解析修复与实测

1. 页面书名位于 `.novel-name`，`h1` 是站点 Logo；支持繁体“最新章節”、本书编号对应的封面、嵌套简介与状态。
2. 正文当前使用 `.contents`，旧规则只识别 `#content` / `.content`，会得到空正文。兼容新容器，清理开头书名、箭头及标点导航，按完整明智屋水印边界排除推荐书单、翻章按钮，保留小说内普通“新書推薦”叙述。
3. DOM 与 HTML 网页识别同步读取实际书名、作者和封面。网页导入改用已验证的专用解析器重取完整目录与详情，避免目录页缺封面、通用正文链路不匹配。
4. 章号统计支持繁体“兩 / 萬 / 節”及开头卷名；只修正统计，不改原目录标题、顺序或补造章节。

| 书籍                         | 目录条目 | 首 / 中 / 末正文字符数 |
| ---------------------------- | -------: | ---------------------- |
| 都重生了誰考公務員啊 `42628` |      782 | 2547 / 2761 / 1493     |
| 凡人修仙傳 `17482`           |     2455 | 2746 / 3456 / 1223     |

两本书的目录数量、首末条目由独立 HTMLParser 再次核对。保存的实际目录又分别运行 App HTML 识别和最终注入脚本（JSDOM），两条路径的全部章节地址、标题及顺序一致。目录页自身不提供封面时留空，导入再取详情补齐。

记录：[实际网络解析](./mingzw-doh.json)、[独立目录核对](./mingzw-independent-catalog.json)、[DOM / HTML 对照与最终章号统计](./mingzw-recognizer.json)。网络记录里的章号统计生成于卷名兼容前，以最后一份统计为准。只保存元数据、字数与请求状态，没有保存小说全文。

目标书原站当前只到第 786 章，含 4 条非章号条目；条目数与其他书源不同不能直接推断解析漏章。实际目录仍有跳号、标题笔误或拆章，统计提示不等于判定缺章。以上验证了目录提取及首中末正文抽样，未逐章校对整本小说。
