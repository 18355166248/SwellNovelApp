# 轻读：私人阅读空间计划

目标不是堆叠阅读器功能，而是让用户的书、阅读进度和阅读痕迹可拥有、可迁移、可恢复。
在线能力优先使用用户自己控制的 WebDAV 空间，不建立必需的应用账户体系。

## 第一阶段：本地备份与恢复

当前进度：v1 已完成导出、完整校验和确认后的整库替换恢复。合并恢复与按书选择恢复会在跨设备同步的冲突处理阶段实现。

交付一个可离线使用的书库备份文件，包含：

- 书籍元数据、书架顺序、阅读进度、书签、设置和阅读统计。
- 本地 TXT 正文，以及用户选择保留的在线章节缓存。
- 版本号、创建时间、文件清单和校验和。

恢复先解压到临时位置并完成校验，再执行确认后的整库替换。任何失败或中断都不能覆盖原有书库。

验收：清空应用数据后，可通过备份完整恢复书架、正文和续读位置；损坏备份会被拦截并给出原因。

## 第二阶段：WebDAV 云端备份

当前进度：已完成 WebDAV 连接测试、手动上传、云端列表、下载恢复与删除；仅接受 HTTPS。iOS/Android 凭据已使用系统安全存储，Web 端仅在当前浏览器会话保存；云端备份包的用户密码加密仍待补齐。

在“我的”中增加一个可选的 WebDAV 备份入口。用户填写自己的服务地址、用户名和应用密码，应用将第一阶段生成的加密备份包上传到指定目录。

- 支持手动上传、下载、查看最近备份和删除旧备份。
- 默认仅在用户明确操作时联网，不做隐式上传。
- 备份文件以时间戳和设备标识命名，避免覆盖。
- iOS 与 Android 使用系统安全存储保存凭据；Web 端默认只在当前会话保存密码。
- 不在仓库、日志、错误上报或备份文件中保存明文密码。

验收：可用任意标准 WebDAV 服务完成上传、列出、下载与恢复；认证失败、网络中断和空间不足都有可理解的处理。

## 第三阶段：跨设备增量同步

云端备份和实时同步不是一回事。同步阶段在 WebDAV 中维护一份轻量索引，只上传变化的数据：

- 双向同步书架、进度、书签、笔记与设置。
- 正文按内容哈希去重，避免每次同步重复上传大文件。
- 阅读进度按最新更新时间合并；书签和笔记按 ID 合并；发生无法自动判定的冲突时保留两个版本供用户选择。
- 同步前显示变更摘要，提供仅 Wi-Fi、手动同步和暂停同步开关。

验收：两台设备先后阅读、添加书签后可正确合并，离线修改再次联网不会静默丢失内容。

## 第四阶段：网络追更工具

将在线书源作为可选的“找书、收藏、追更、省心”能力，不影响本地书籍的导入、打开和阅读。

- 为在线书籍增加追更状态、最近检查时间和未读章节数。
- 建立追更收件箱，集中展示已收藏书籍的新章节，并支持一键缓存或直接续读。
- 增加书源健康检查、失败提示与手动切换；单个书源异常不能阻塞其他书籍。
- 支持用户管理书源开关、检查频率和仅 Wi-Fi 下载偏好。
- 在 HTTPS 生产代理和真实后台任务稳定后，再提供系统通知；未具备后台能力时不展示虚假的提醒开关。

验收：收藏书籍更新后可正确识别新增章节；断网、代理异常或书源页面变化时，本地书库和已缓存章节仍可正常使用。

## 基础约束

- WebDAV 地址和账号始终由用户自行配置；不为特定云服务硬编码凭据或私有地址。
- 传输必须使用 HTTPS；敏感凭据不进入 Git、调试日志或错误信息。
- 每个阶段完成后必须通过 `npm run check`，并在 iOS、Android、Web 上验证关键路径。
