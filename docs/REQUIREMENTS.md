# 轻读：产品现状与迭代需求

**版本：** 1.0.0
**更新日期：** 2026-07-10

## 1. 产品定位

轻读是一款本地优先的中文小说阅读器。第一目标是让用户稳定导入、管理并长时间阅读自己的
TXT 书籍；在线书源是辅助能力，不应影响本地阅读的可靠性。

支持平台：

- iOS 15.1+
- Android 7.0 / API 24+
- 现代桌面与移动浏览器

## 3. 发布前质量门槛

每次发布必须满足：

- TypeScript 无错误
- ESLint 无 error
- 完整 Jest 测试通过
- Web Production 构建通过
- iOS Simulator 与 Archive 构建通过
- Android Debug 构建通过，Release 签名配置校验通过
- 版本号在 package.json、iOS 与界面一致
- 10MB TXT 导入、启动、翻页和恢复位置回归通过

当前外部阻塞：生产书源代理仅支持 HTTP。商店发布前应迁移到 HTTPS 域名，随后关闭 iOS
`NSAllowsArbitraryLoads` 全局例外。

## 5. 非目标与原则

- 未实现后台任务前，不展示“更新提醒”开关。
- 未实现账户同步前，不使用“同步中”等误导文案。
- 不把在线书源失败扩散为本地书籍不可读。
- 不在发布包中内置未经许可的小说内容。
- 新增大功能前优先保持测试、Lint 和三端构建全绿。
